Feedback prompt samples

Make the game easier to understand

Please revise the game so the goal is clearer. Add a short start screen, clearer instructions, and better visual feedback when the player scores or loses.

Adjust difficulty

Please keep the same game idea, but make the difficulty ramp up more slowly. The first 20 seconds should feel easier for beginners, then gradually become more challenging.

Improve the visuals

Please improve the art direction of the game. Keep it simple, but make the colors more lively, the player easier to recognize, and the buttons and score display more polished.

Add one feature without changing everything

Please keep the current game mostly the same, but add a restart button, a timer, and a simple sound effect when the player earns points.
